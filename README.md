# Burrow Pet Environment Monitor

The Burrow Pet Environment Monitor is an open source device which passively monitors temperature, humidity and air quality within your pet's environment, compares against a researched list of known safe values, and alerts you of any concerns through mobile notifications and Alexa announcements
